# Zhixuan Zhao — Academic Homepage

A simple English research homepage based on [luost26/academic-homepage](https://github.com/luost26/academic-homepage) (MIT License).

## Update the content

- Personal information, biography, education, and experience: `_data/profile.yml`
- Publications: `_publications/`
- Portrait: `assets/images/photos/zhixuan-zhao.jpg`

## Preview locally

With Ruby 3.3, install the gems in `Gemfile`, then run `bundle exec jekyll serve` from this folder. The preview appears at `http://127.0.0.1:4000/`.

## Publish with GitHub Pages

Create a repository named `<your-github-username>.github.io`, push this folder to its `main` branch, and select **Settings → Pages → Deploy from a branch → main / (root)**. The site will appear at `https://<your-github-username>.github.io/`.
